## 关于这些数字

- §3.4 的读数是 **2026-09-21 的一次性人工盘点，不是验收基数**。§3.4 明确
  「数字变化不等于回归」。本目录的报告是工具按自己的口径**重算**的，不是对 §3.4 的校验。
- 工具**不写死任何条数**。书源新增后重跑 `audit.py --publish docs/book-source-audit`
  即自动纳入，并按生成日期出新报告。
- 「零命中」的检查同样列在报告里，用来确认口径生效——不是所有检查都必须报出问题。

## 脱敏边界（§3.4）

入库的只有**聚合读数**：计数、分桶、结构指纹、布尔旗标。

**不入库**的：原始压缩包、书源名称与 URL、完整 Header、Cookie、登录数据、
真实内容调试响应、选择器原文、正文。逐源清单（`inventory.jsonl`）默认只落在本机
`.book-source-audit/`，用 `url_hash`（SHA-256 前 12 位）作标识。

诊断卡里出现的 `url_hash` 就是这套脱敏标识。

### 还有一处需要你裁决

语料 **D03** 预期**保留**标题、**I01** 预期**删掉**重复的一行，而现存缺陷是「标题行没被删掉」。
**「删」与「不删」定错就会把它们改坏。** 诊断卡 06 采取的立场是「只在正文首行 == 目录标题时删，
且删除只发生在展示副本」，请确认或推翻。
