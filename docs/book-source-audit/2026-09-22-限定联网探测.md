# P0 限定联网探测（2026-09-22）

## 1. 授权与边界

用户授权：从现有书源压缩包选择代表源；每源每环节请求 1 次，失败最多重试 1 次；
不保存 Cookie、请求头或真实正文。

本轮只完成**站点入口可达性**这一环。选择条件来自已发布静态分群：启用、无 JS/WebJS、
无敏感 Header 旗标，并分别覆盖图片字、正文分页、替换可能命中标签三类。请求只读取最多
512 字节到内存后立即丢弃；仓库只记录脱敏 `url_hash`、状态族、内容类型、耗时和是否跨域跳转。

真机 `10CE5P1M1Z001P9` 当时未连接；又没有一个仍能自然复现的具体书名/章节，因此没有猜测
搜索词、没有执行书源规则，也没有继续请求搜索、详情、目录或正文。这样避免为了“完成 P0”
人为制造问题或扩大授权面。

## 3. 能下与不能下的结论

- 图片字与替换代表源当前入口可达，但跨站跳转；这不等于章节链路可用，更不等于图片字或替换问题复现。
- 分页代表源入口连续两次返回 5xx，只能记录为本轮站点状态，不能推断 `nextContentUrl` 有缺陷。
- 三类都没有产生可授权实施的 App 通用层问题；后续只有自然遇到具体书名/章节时才补四阶段快照。
- “历史反馈当前难以复现”不再阻塞 P0。它被记录为待自然复现的证据池，同时严格禁止在无样本时修改通用解析语义。
