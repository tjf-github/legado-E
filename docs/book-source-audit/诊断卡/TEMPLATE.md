# 书源诊断卡模板

《书源与解析优化计划书》§5 A1 规定每个待修书源使用同一张卡。本文件是模板，
填写示例见同目录 `01` … `05` 各卡。

**脱敏边界**（§3.4）：卡里只写脱敏摘要。「书源名称」一栏在**本机**填写，
入库版本写「见本机逐源清单」；脱敏标识统一用 `url_hash`（`bookSourceUrl` 的 SHA-256 前 12 位，
由 `tools/book-source-audit/` 生成）。复现关键词只留脱敏摘要，不收录真实用户内容。
