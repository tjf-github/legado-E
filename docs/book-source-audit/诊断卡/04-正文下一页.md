自引用检查为零是**好消息**，说明 §6 B0 提到的「下一页循环」不是靠「同值自引用」这种
最直白的形态出现的。但这**不等于**没有循环风险：`nextContentUrl` 是一个规则而非 URL，
循环可能来自规则在每一页都命中同一个链接（例如页脚「下一页」按钮在末页仍指向自身），
那要在运行时才能观察到。

### 页边界空白是通用层已知的一处

`BookContent.kt:167` 用 `contentList.joinToString("\n")` 拼接各页，之后统一走
`HtmlFormatter`。`case-03-next-page` 已冻结这个行为，对应不变量
`INV-PAGE-EMPTY-1` / `INV-PAGE-EMPTY-2`：页边界两侧的成片空白不得产生连续空行，
也不得产生重复缩进。

这一条与本卡的关系：它是 2030 条分页源**共用**的路径，任何改动的影响面都远大于单条书源。

## 9. 与 P0 退出条件的关系

`next_content_url_self_ref = 0` 说明**至少最直白的循环形态不存在**，这是一个可离线得出的
否定结论，有价值。

但「分页是否真的循环、末页是否被判成空正文」只能联网观察。
在拿到具体分页书源 + 章节之前，本卡明确归入「仅真实站点可复现」，满足 P0 的分类退出条件，
但**不进入通用层改动**。后续只在自然遇到可复现章节时补四阶段快照，不要求用户专门寻找。
