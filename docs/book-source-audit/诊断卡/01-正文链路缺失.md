### 3.4 相关但另计：发现入口的列表规则为空 —— `explore_book_list_empty`

| 项 | 值 |
| --- | --- |
| 计数（全部 / 启用） | **1506 / 924** |
| 判定口径 | `exploreUrl` 非空**且** `enabledExplore` 为真，但 `ruleExplore.bookList` 为空 |

**这一条不要当缺陷看。** 1506 条占全库 24.5%，比例高到不可能是逐条写错。更可能是
「发现页靠 `exploreUrl` 直接把 JSON/HTML 交给通用解析」这类写法，此时 `bookList` 为空是
正常配置。它列在这里是为了**划清界限**：3.1—3.3 的小计数才是可逐条核实的候选，
这一条在 P1 联网抽样确认口径之前不做任何结论。
