# D-2 裁定：阶段四补打的身份匹配口径

- 日期：2026-09-26；裁决人：用户（controller 出结论与最小修法）
- 来源：`.agent-protocol/tasks/book-source-p1-device/findings.json` **F-0009**（medium，open）；reviewer-r002 补充的同类反例（`book.origin` 与 `bookSource.bookSourceUrl` 也要求逐字相同）
- 结论：**立项**（诊断可用性缺陷，低优先级；不阻塞 P2，不做 P2 前置）

## 1. 事实（均为当前代码可复核）

| # | 事实 | 位置 |
| --- | --- | --- |
| 1 | 会话身份靠**逐字相等**：书源必须等、章节必须等、绑定过书号时书号也要等 | `help/book/diagnostics/BookSourceDiagnostics.kt:92-99`（`accepts`） |
| 2 | 两个调用点喂进来的**书源字段不是同一个**：抓取路径用 `bookSource.bookSourceUrl`，阅读路径用 `book.origin` | `model/webBook/BookContent.kt:52`；`help/book/ContentProcessor.kt:110` |
| 3 | `--<url>` 入口只把用户输入的串塞进 `chapter.url`，`book.bookUrl` 留空 | `model/Debug.kt:315-324`（绑定在 `:422`） |
| 4 | 章节 URL **按规则原文存库，可以是相对路径**（不做入库前绝对化） | `model/webBook/BookChapterList.kt:239` |
| 5 | 请求时才归一：`NetworkUtils.getAbsoluteURL(baseUrl, url)`；章节自身的绝对形式已有现成方法 `BookChapter.getAbsoluteURL()` | `model/analyzeRule/AnalyzeUrl.kt:227`；`data/entities/BookChapter.kt:171-182`（调用见 `model/webBook/WebBook.kt:400,448`） |
| 6 | **仓内已有「比较前先归一」的先例**：正文下一页的护栏就是拿 `NetworkUtils.getAbsoluteURL(redirectUrl, …)` 比两侧 | `model/webBook/BookContent.kt:100-101` |

由此，阅读路径（阶段四唯一的产生地）只在「书的 `origin` 与章节的 `url` **逐字等于**调试会话绑定的那两串」时才补打。两种常见情形必然落空：

- 调试页粘的是**绝对 URL**，而书里章节存的是**相对路径** → 永不补打；
- 书的 `origin` 与当前书源 URL 不逐字相等（书源 URL 改过、经 `sortUrls` 变体添加、导入数据带尾斜杠差异）→ 永不补打。

## 2. 为什么必须修（而不是只写文档）

失效不是「安静地少一行」，而是**贴错标签**：调试链路收尾时 `finishContentDiagnostics()` 把第 4 行标为「未执行」，理由是固定的
「书源调试链路止于 BookContent，**未进入阅读处理**」（`Debug.kt:453-461`）。在 D-2 场景里阅读处理**明明执行了**，只是身份没匹配上，用户读到的却是一句错误的因果说明。
后续 P2/P3 的调试会据此得出「阶段四没执行」的结论——这正是《书源与解析优化计划书》§2 第 5 条「每层都可验收」要避免的误判。

影响面仅限诊断特性：不碰正文、缓存、请求与阅读语义，故定**低优先级**。

## 3. 最小修法（后续任务书可直接引用）

- **M1 章节 URL 规范化比较**（必须）：比较前把两侧统一成绝对形式——阅读侧有 `BookChapter`，直接用 `getAbsoluteURL()`；
  `--<url>` 入口绑定的本就是用户粘的绝对串，与归一后的阅读侧比较即可。不引入新的 URL 规范化实现。
- **M2 书源身份同样归一再比**（必须，与 M1 同批）：`book.origin` 与 `bookSource.bookSourceUrl` 先去尾斜杠/去查询再比；
  仍不等时，检查二者是否同属该书的书源 `sortUrls()` 集合。**不通过域/同站放宽**（那会推翻 S5 的隔离证据）。
- **M3 不匹配要可见**（必须，性价比最高）：身份不匹配时不补打，但把第 4 行的说明改成
  「本次阅读的书源/章节身份与调试目标不一致，未补打」，把静默失效变成可读事实。M1/M2 只做一半时本条也必须落。

**边界（不做）**：不放宽成「同域名即接受」；不做查询串排序归一；不把匹配键写进数据库；不改任何正文路径语义。
